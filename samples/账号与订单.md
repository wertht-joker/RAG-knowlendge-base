# 账号与订单说明

## 账号注册与登录

1. 使用手机号或邮箱注册账号；
2. 设置密码（8-20 位，包含字母和数字）；
3. 忘记密码可通过手机验证码重置。

## 账号安全

- 请勿将账号密码泄露给他人；
- 建议开启两步验证，提升账号安全性；
- 如发现账号异常登录，请立即修改密码并联系客服。

## 订单查询

登录后进入「我的订单」页面，可按状态筛选查看订单，支持查看订单详情和物流信息。

## 订单修改与取消

1. **修改地址**：订单未发货前可修改收货地址；
2. **取消订单**：待付款状态可随时取消，已付款订单需联系客服；
3. **申请退款**：已付款订单可在线申请退款，审核通过后退回原账户。

## 订单状态说明

| 状态 | 说明 |
|---|---|
| 待付款 | 已下单未支付 |
| 待发货 | 已支付待仓库发货 |
| 已发货 | 已发出，可查物流 |
| 已完成 | 已签收确认 |
| 已取消 | 订单已取消 |
