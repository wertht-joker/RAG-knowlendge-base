# 智能空气净化器 X1 产品手册

## 产品简介

智能空气净化器 X1 采用 H13 级 HEPA 滤网，可有效过滤 PM2.5、花粉、细菌等污染物，净化效率高达 99.97%。

## 主要功能

1. **自动净化模式**：内置激光传感器，实时监测空气质量，自动调节风速。
2. **睡眠模式**：夜间低噪音运行（低于 30 分贝），灯光自动熄灭。
3. **定时功能**：支持 1/2/4/8 小时定时关机。
4. **APP 远程控制**：通过手机 APP 可远程开关、查看空气质量数据。

## 技术规格

| 参数 | 数值 |
|---|---|
| 适用面积 | 20-40 平方米 |
| 噪音 | ≤35 分贝 |
| 额定功率 | 45W |
| 滤网寿命 | 约 6-12 个月 |

## 滤网更换

当指示灯变红或 APP 提示滤网寿命到期时，需要更换滤网。更换方法：断电后打开后盖，取出旧滤网，装入新滤网并复位计时器。

## 常见故障排查

- 无法开机：检查电源线是否插紧。
- 出风量变小：滤网可能堵塞，请清洁或更换滤网。
- 空气质量数值异常：传感器窗口有灰尘，请用软布擦拭。
